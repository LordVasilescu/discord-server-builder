## 7. Visual assets

### Server icon
**Vibe:** glowing logo on black, scanlines optional
- Generate via Midjourney / Leonardo.AI / Bing Create with prompt:
  > `cyberpunk circuit emblem, neon magenta and cyan glow, on pure black, minimal, high contrast, square logo, scanlines`
- Or steal a free one: search `itch.io` for "cyberpunk icon pack" (most are CC0 / royalty-free)

### Server banner (Boost level 2 unlocks this)
**Vibe:** night-city skyline, neon grid, or pure abstract glitch
- Prompt: `cyberpunk skyline at night, neon pink and cyan reflections, rain, ultra wide, cinematic, no people`

### Custom emoji (Discord = 50 free slots)
Upload these for max vibe — search "cyberpunk emoji pack" on:
- emoji.gg → category: cyberpunk / neon / synthwave
- discadia.com

## 10. Apply order

1. Build the structure first (SETUP.md Phases 1–5) using **plain names** so you don't get confused mid-setup
2. Once it works, do a **rename pass**:
   - Server name + tagline + icon
   - All role names + colors (this file §3)
   - All category names (this file §4)
   - All channel names + topics (this file §4 + §9)
3. Then post the **cyberpunk pinned messages** (this file §5)
4. Last: **upload custom emoji** + tweak bot prefix/welcome (this file §7 + §8)

Doing it in two passes (function first, skin second) means a typo in the rename never breaks your permission overrides.
